# Flaminguage 🔥

## About Flaminguage

**Flaminguage** is an educational English vocabulary learning application developed during **2025–2026** to help learners build practical vocabulary through visual learning, interactive exercises, and educational games.

The application is particularly designed for learners who need practical English vocabulary for **immigration, travel, studying abroad, and everyday life in English-speaking countries**.

Flaminguage combines structured vocabulary lessons with interactive assessments, vocabulary games, and an integrated dictionary to provide learners with different ways to study, practice, and review English vocabulary.

The initial concept and visual identity of Flaminguage were inspired by the **migration of flamingos**. This idea became the foundation for the application's theme, visual elements, icons, and educational presentation, with flamingos and bird-inspired elements incorporated throughout the design.

---

## Target Audience

Flaminguage is primarily intended for:

* English language learners
* People preparing for immigration
* Students preparing for international study
* Travelers
* People preparing to live or work in English-speaking environments
* Learners who want to build practical everyday vocabulary

---

## Learning Categories

The vocabulary is organized into six thematic categories:

1. **Daily Services Provider Places**
2. **Economic Services**
3. **Educational Places**
4. **Government Places**
5. **Places**
6. **Residence**

Each vocabulary item is presented with:

* 🖼️ An illustrative image
* 📖 The meaning of the word
* 🔊 Pronunciation

The use of visual association is intended to help learners connect English words with concepts and real-world places, making vocabulary recognition and retention more engaging.

---

## Learning Progression

Flaminguage uses a sequential learning structure.

Learners begin with the available category and study its vocabulary before completing a multiple-choice assessment at the end of the category.

After completing the assessment, the learner receives a score and the next category becomes available.

> **Current Version:** There is no minimum passing score required to unlock the next category. Completing the assessment is currently sufficient to progress.

A future version may introduce a minimum score requirement to provide a more structured mastery-based progression system.

---

## Vocabulary Typing Challenge ⌨️

Flaminguage includes an interactive typing game designed to reinforce vocabulary recognition, recall, and typing skills.

Words appear at the top of the game area and gradually move toward the bottom. The player must type the displayed word before it reaches the bottom.

The game starts with **10 lives**.

* ⌨️ Type the displayed word before it reaches the bottom
* ❤️ Start with 10 lives
* ❌ Missing a word removes one life
* ⚡ The difficulty and speed gradually increase
* 🎵 Background music is available during gameplay
* 🖱️ The background music can be changed using the **right mouse button**

The typing challenge provides an active form of vocabulary practice, requiring learners to recall and enter words rather than simply recognize them.

---

## Vocabulary Quiz 🎯

The Vocabulary Quiz provides another way to review and test vocabulary knowledge.

Before starting the quiz, the learner can choose the **number of questions** they want to answer.

The questions are selected randomly from the application's vocabulary, allowing learners to practice words across different categories.

This approach makes it possible to create different quiz sessions without requiring the learner to follow the category order used by the main learning modules.

---

## Dictionary 📚

Flaminguage includes an integrated dictionary containing the application's vocabulary in one place.

Each dictionary entry provides:

* The English word
* Its meaning
* An explanatory or example sentence

The dictionary is intended to serve as a reference for reviewing vocabulary and understanding words in context.

> **Note:** The current version does not include a search function.

## Design and Visual Identity

The visual concept of Flaminguage was developed around the theme of **flamingos and migration**.

The idea of flamingos moving between different environments provided the initial creative direction for the application. This concept was then reflected in the visual identity, icons, interface elements, and educational content.

The design aims to create a consistent visual language throughout the application while keeping the learning environment approachable and engaging.

Customized panels and interface components were also used in the application's front-end to provide greater control over the visual presentation and user experience.

---

## Development Process

Flaminguage was developed during **2025–2026** as an educational software project and as a practical application of software development concepts.

The initial ideas, design discussions, and educational exercises were explored together with **two students** as part of their learning experience. These activities were intended to expose them to the stages involved in designing and producing a software application, including idea development, visual thinking, user-interface considerations, and discussing possible features.

Their participation was part of the **educational process surrounding the project** and was intended to provide learning opportunities and practical experience.

The software architecture, implementation, programming, integration, final design decisions, and development of Flaminguage were carried out by **SPH**.

This approach allowed the project to function not only as an application but also as a practical environment for demonstrating how an idea can progress through planning, design, implementation, testing, and refinement.

---

## Student Learning Version and Pronunciation

During the educational development process, a separate classroom version used **recordings of the students' own voices** for pronunciation content as part of the learning experience.

The purpose was to familiarize students with aspects of audio recording, content preparation, processing, and integrating audio resources into a software application. It also provided a more direct connection between the learners and the application they were studying.

The **final public release does not include those personal voice recordings**. Instead, the final version uses digital, non-human pronunciation resources for the vocabulary content.

## Educational Purpose

The primary purpose of Flaminguage is to make practical English vocabulary learning more interactive and engaging.

Rather than presenting vocabulary only as a conventional list of words, the application combines several learning approaches:

* **Visual association** through images
* **Meaning and explanation** for each vocabulary item
* **Pronunciation** for language exposure
* **Multiple-choice assessment** for vocabulary review
* **Typing practice** for active recall
* **Randomized quizzes** for additional practice
* **Dictionary reference** for reviewing vocabulary in context

The application focuses particularly on vocabulary that can be useful in real-world situations, including places and services that learners may encounter when traveling, studying, working, or living abroad.

## Programming and Technology

One of the notable differences between Flaminguage and some of the developer's earlier educational projects, such as **Funtomin** and **World of Words**, is the programming language used for the application.

While earlier projects were developed using **VB.NET**, Flaminguage was developed using **C#**, with an emphasis on improving code readability, maintainability, and overall implementation quality based on experience gained from previous projects.

The project also uses **NAudio** for audio and music playback.

### Technologies Used

* **Programming Language:** C#
* **Framework:** .NET Framework 4.5
* **Database:** Microsoft Access
* **Database Access:** OleDb
* **Audio Library:** NAudio 1.8.0
* **Development Environment:** Visual Studio

The development process also involved customized front-end panels and interface components to provide greater control over the application's visual presentation.

## Installation

Flaminguage does not require user registration or an activation key.

To install and run the application:

1. Download the latest release from the **Releases** section.
2. Download the application package.
3. If required by your system configuration, install **Microsoft Access Database Engine** separately.
4. Install or extract the Flaminguage application according to the provided release package.
5. Launch **Flaminguage**.
6. Start learning and exploring the available vocabulary categories.

> **Important:** Microsoft Access Database Engine is not included with Flaminguage. If it is required on your system, it must be downloaded and installed separately from Microsoft.

## Known Limitations

Flaminguage is an educational software project that is still under development.

The current version has some known limitations:

* The dictionary does not currently provide a search function.
* The category progression system does not currently require a minimum passing score.
* Image loading and resource management can benefit from further optimization.
* Some planned educational and gameplay features have not yet been implemented.

These limitations are part of the project's current development stage and may be addressed in future versions.

Users are welcome to report bugs, suggest improvements, and provide feedback through the project's GitHub repository.
